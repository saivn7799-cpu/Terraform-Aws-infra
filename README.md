# Terraform-Aws-infra

Production-ready Terraform project implementing Infrastructure as Code (IaC) for AWS using a modular architecture and DevOps best practices.

## Features

- Infrastructure as Code with Terraform
- Modular project structure
- AWS resource provisioning
- Remote state management (S3 & DynamoDB)
- Multi-environment support (Dev, QA, Prod)
- Reusable Terraform modules
- Scalable and maintainable infrastructure

## Technologies

- Terraform
- AWS
- Amazon VPC
- EC2
- IAM
- S3
- DynamoDB
- Git & GitHub

```bash
terraform init
terraform plan

```
